Phần 1 · SGK trang 26–27

1. Phương trình tích

Muốn giải phương trình tích (ax + b)(cx + d) = 0, ta giải hai phương trình bậc nhất ax + b = 0 và cx + d = 0, rồi lấy tất cả các nghiệm của chúng.

(ax + b)(cx + d) = 0  ⇔  ax + b = 0  hoặc  cx + d = 0

Ví dụ 1 (SGK trang 26)

Giải phương trình: (x + 3)(2x − 5) = 0

  1. x + 3 = 0 ⇒ x = −3
  2. 2x − 5 = 0 ⇒ 2x = 5 ⇒ x = 5/2
  3. Vậy phương trình có hai nghiệm x = −3 và x = 5/2.

Ví dụ 2 · Phân tích thành nhân tử

Giải phương trình: x² − 4 + (x + 2)(2x − 1) = 0

  1. Viết x² − 4 = (x − 2)(x + 2).
  2. Đặt nhân tử chung (x + 2): (x + 2)[(x − 2) + (2x − 1)] = 0.
  3. Thu gọn: (x + 2)(3x − 3) = 0 ⇒ x = −2 hoặc x = 1.
Phần 2 · SGK trang 28–30

2. Phương trình chứa ẩn ở mẫu

Đối với phương trình chứa ẩn ở mẫu, các giá trị của ẩn làm cho ít nhất một mẫu thức bằng 0 không thể là nghiệm. Điều kiện để tất cả các mẫu thức khác 0 gọi là điều kiện xác định (ĐKXĐ) của phương trình.

  1. Bước 1: Tìm điều kiện xác định của phương trình.
  2. Bước 2: Quy đồng mẫu hai vế của phương trình rồi khử mẫu.
  3. Bước 3: Giải phương trình vừa nhận được.
  4. Bước 4 (Kết luận): Trong các giá trị tìm được ở Bước 3, các giá trị thỏa mãn ĐKXĐ chính là các nghiệm của phương trình đã cho.
Lưu ý quan trọng: Nếu giá trị tìm được ở Bước 3 làm mẫu bằng 0 (vi phạm ĐKXĐ) thì phải loại nghiệm đó!

3. Máy kiểm tra nghiệm phương trình tích & chứa ẩn ở mẫu

Thử kiểm tra giá trị x cho phương trình chứa ẩn ở mẫu: (x + 3)/(x − 2) = 5/(x − 2) (ĐKXĐ: x ≠ 2).
